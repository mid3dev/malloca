Questions

Good to know

Why is there an application fee?

The KES 500 fee covers administrative processing, verification of your details and interview scheduling. It is a one-time fee per application and is non-refundable once your application has been submitted.

How do I pay the application fee?

Use M-Pesa → Send Money and send KES 500 to 0759 725 070. You'll receive an SMS with a 10-character transaction code (e.g. SJ12ABC34D). Enter that code on the payment step to unlock submission. If you have any problem, call or WhatsApp 0759 725 070.

My transaction code was rejected — what do I do?

Double-check the code matches your M-Pesa SMS exactly (10 characters, letters and numbers). If you just paid, wait 1–2 minutes and try again. If it still fails, call or WhatsApp 0759 725 070 with your M-Pesa message and we'll verify manually.

Is the fee refundable if I'm not shortlisted?

No. The fee pays for processing your application regardless of the outcome. Only pay if you're comfortable with this. We clearly display the fee before you pay — there are no hidden charges.

How will I know my application went through?

You'll receive a reference number on screen immediately after payment verification. Shortlisted candidates are contacted by phone or email within 7 working days. For follow-up, call 0759 725 070.

Do I need experience to apply?

Not for every role. Barback, housekeeping, butcher assistant and service assistant roles include training. Butcher, bartender, security and DJ positions require relevant experience.
